## ⭐⭐ 用户在问答中暴露的三类固定失误（讲课时要主动防）

1. **抓错技术词（2 次）**：serialization ↔ recompilation；compilation cost ↔ compute cost。**概念是对的，伸手抓词时抓了旁边那个。** 在四选一里这就是选错和选对的距离——错误选项常常就是"把正确句子里的一个术语换掉"。
2. **自己编因果链（1 次）**：拿两个都认识的正确概念，用一个假的"所以"连起来（列存→擅长位掩码→**所以**配 SIMD）。⭐ **这比说不清楚更危险，因为考卷的错误选项就是这么造的**（例："既然每列都是单一数据类型，**所以**可以统一用一种压缩方案"）。
3. **有标签无机制（反复）**：记住了结论的名字（"data have more similarity"、"Huffman 要解码"、"要查 vtable"），但说不出底下一层的机制。**四个选项全挂着正确标签时，只有机制能做区分。**

**有效的对策（已验证）**：讲完每个点后追问"再往下一层是为什么"；C-Store 那一轮明显好转，说明"讲透机制 + 立刻用英文简答检验"这个循环有效，继续用。

## ⭐ 用户明确要求的授课格式（必须遵守）

- **中英双语**：中文把道理讲透；英文按**考卷措辞**写，引号里的句子基本可以直接背（因为考试是英文 MCQ，需要认得原文长什么样）。
- **说人话，不要 AI 提纲腔**：少加粗、少用 ⭐ 堆砌、少用编号小节；用**连贯的散文 + 生活比喻**，不要条目堆砌。用户原话："你不能再像 AI 一样说话了"。
- **高中生能懂的逻辑**：先建一个具体场景或比喻（超市小票 / 流水线递交 / 搬砖 / 拧瓶盖机器 / 摩尔斯电码），再引出术语；不预设用户知道 vtable、序列化、多态这些词。
- **每块讲完出 2 道英文简答题**，用户会用英文作答以模拟考试；批改要**诚实**（他要的是真实反馈，不是鼓励），指出方向对/机制缺/用词错分别在哪。
