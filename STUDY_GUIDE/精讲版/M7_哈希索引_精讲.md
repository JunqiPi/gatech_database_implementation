## 1. 索引 + map vs unordered_map

**📖 原文：** *"std map maintains key value pairs in a sorted order using a balanced binary search tree... unordered map uses a hash table... average case complexity of O(1)."*

**💡 大白话：** **索引** 像书的目录,让你不用逐行扫就能定位。C++ 两种索引容器:
| | `std::map` | `std::unordered_map` |
|:---|:---|:---|
| 底层 | 平衡 BST(红黑树) | **哈希表** |
| 顺序 | **有序** | 无序 |
| 复杂度 | O(log n) | 平均 **O(1)**,最坏 O(n) |
| 擅长 | **范围查询** | 最快单点查找 |

**📝 考试这么考(练习题 Q3)：**
- ✅ *"Prefer `std::map` for efficient range queries (it's sorted)."*
- ❌ *"Prefer `std::map` for average-case O(1)."* —— 错!那是 unordered_map。

---

## 2. ⭐ 哈希表机制 + 冲突

**📖 原文：** *"To store data, we apply the hash function on the key to calculate which slot... When two different keys hash to the same slot, it is known as a hash collision."*

**💡 大白话：** 哈希表像一排**抽屉柜**,用哈希函数(如 `key mod 10`)直接算出 key 在哪个抽屉,不用挨个翻。
- 存 15:15 mod 10 = 5 → 放 slot 5。存 26 → slot 6。存 56:56 mod 10 = 6,但 slot 6 占了 → **冲突(collision)**!
- 取:用同一哈希函数算槽,比对 key;**遇到空槽 = key 不存在**。
> 🔵 类比:衣帽间按号码挂钩,直接走到第 5 号钩,不用一个个找。

---

## 3. 线性探测 + 复杂度 + 主聚簇

**📖 原文：** *"With linear probing, if the intended slot is occupied, we check the next slot... the formula... is hash(key) + K mod table size... This phenomenon is known as clustering."*

**💡 大白话：** **线性探测**:冲突就**逐个看下一槽**,公式 `(hash(key) + k) mod size`,k=0,1,2…。
- 复杂度:无冲突 **O(1)**;高冲突(表满/坏哈希)退化 **O(n)**。
- **主聚簇(primary clustering)**:连续被占的槽形成长"块",越长越易再冲突,雪球效应。

**📝 考试这么考：**
- ✅ *"An empty slot during search means the key is absent."*
- ❌ *"Linear probing fully eliminates clustering."* —— 错!它**产生**主聚簇。

---

## 4. ⚠️ 懒删除（lazy deletion）

**📖 原文：** *"When we remove a key... that leaves a hole in the table that disrupts the probing sequence... A simpler solution is to mark an entry as deleted by setting a flag."*

**💡 大白话：** 直接删一个 key 会留**空洞**,**破坏探测链**——后面的 key 探测到这个洞就误判"不存在"。**解法:懒删除**——加 `exist` 标志,删除只置 false(标记"已删"),探测时遇"已删"继续往后探。用 `std::optional` 表示空槽。
> 🔵 类比:图书馆书被借走,书架上留个"此处暂缺"的牌子(而非直接抽掉隔板),这样按位置找书的逻辑不乱。

**📝 考试这么考：**
- ✅ *"Lazy deletion marks an entry deleted to preserve the probe sequence."*
- ❌ *"Just clear the slot on delete."* —— 错!留洞断链。

---

## 5. ⭐ 二次探测 vs 双重哈希（解决聚簇）

**📖 原文：** *"Quadratic probing uses the formula K^2 for the Kth probe... Double hashing introduces a second hash function HASH2 to compute the probe step, creating a unique probe sequence for each key."*

**💡 大白话：**
| 探测法 | 公式(第 k 次) | 解决 | 遗留 |
|:---|:---|:---|:---|
| 线性 | `h + k` | — | 主聚簇 |
| **二次** | `h + k²` | 减**主聚簇**(跳更大间隔) | 仍有**二次聚簇** |
| **双重哈希** | `h1 + k·h2` | 几乎消除**二次聚簇** | — |

- **二次聚簇(secondary clustering)**:不同 key 若**初始槽相同**,会走**完全一样的探测序列**(都按 +k² 跳)→仍扎堆。
- **双重哈希**:用**第二个哈希 hash2** 定步长,**每个 key 探测序列都不同**。如 `hash2 = 1 + key mod (size-1)`。
> ⚠️ **hash2 必须 ≠ hash1**!否则退化成相同序列,失去意义。

**📝 考试这么考：**
- ✅ *"Double hashing gives each key a unique probe sequence; hash2 must differ from hash1."*
- ❌ *"In double hashing, hash2 should equal hash1 for consistency."* —— 错!

## 📝 M7 出题风格英文速记（✅对的 / ❌陷阱）

| 考点 | ✅ 对的英文 | ❌ 陷阱 |
|:---|:---|:---|
| map/unordered_map | map=sorted/range queries; unordered_map=avg O(1) | 把两者优点对调(错) |
| 空槽 | empty slot on search = key absent | — |
| 删除 | lazy deletion (mark deleted) preserves probe chain | "clear the slot"(错) |
| 线性探测 | causes primary clustering | "eliminates clustering"(错) |
| 双重哈希 | hash2 ≠ hash1, unique sequence per key | "hash2 = hash1"(错) |

## ✅ M7 一页总结
1. 索引=目录,加速查找;**map=有序BST(范围查询)、unordered_map=哈希(O(1))**。
2. 哈希表:哈希函数算槽,**冲突=两 key 同槽**;搜索遇**空槽=不存在**。
3. **线性探测** `h+k`,产生**主聚簇**;高冲突退化 O(n)。
4. 删除要**懒删除**(标记 deleted),直接清空会断探测链。
5. **二次探测** `h+k²` 减主聚簇但留二次聚簇;**双重哈希** `h1+k·h2` 每 key 独特序列(hash2≠hash1)。
