# 第一块 🔑 高频题干句型（先练"问法"，这是秒懂的一半）

> 考题的"外壳"翻来覆去就这几种。看到这些词，立刻知道它在问什么、有没有坑。

| 英文题干 | 中文 | 你要的反应 |
|:---|:---|:---|
| Which statement about X is **NOT correct**? | 关于 X，哪个说法**不对**？ | ⚠️选**错误**的那个！3 真 1 假，找假的 |
| Which statement is **NOT true**? | 哪个**不成立**？ | 同上，找假的 |
| Which of the following is **incorrect**? | 下面哪个**不正确**？ | 找假的 |
| Which statement is correct? | 哪个**正确**？ | 找真的（注意和上面相反！） |
| Which statement **best captures / best describes** …? | 哪个**最准确地概括/描述**…？ | 选最贴切的 |
| **Why might one prefer** X over Y? | **为什么可能更偏好** X 而非 Y？ | 选 X 的独有优点 |
| **What does** X **guarantee**? | X **保证**了什么？ | 选 X 的定义 |
| What is the **likely impact** on …? | 对…**可能的影响**是什么？ | 推断后果 |
| Which modification is **most likely to improve performance**? | 哪个改动**最可能提升性能**？ | 选最有效的优化 |
| **Assume**: … Which design …? | **假设**：…哪个设计…？ | 按给定条件推 |
| **Consider** [scenario]. Which …? | **考虑**[某场景]。哪个…？ | 把概念套到场景 |
| **Based on the** "…" **paper**, which statement is not correct? | **根据**"…"**论文**，哪个不对？ | 回忆论文论点，找假的 |
| … is incorrect **according to** Codd's paper? | 据 Codd 的论文，哪个**不正确**？ | 回忆论文，找假的 |
| Which of the following is **NOT a** [problem/reason/limitation]? | 下面哪个**不是**一个[问题/理由/局限]？ | 找"不属于"的那个 |

> 🧠 **陷阱词雷达**（圈出来再做）：**NOT, incorrect, not true, EXCEPT, best, most likely, only, always, never, must**。
> 尤其 **NOT / incorrect** —— 最大失分点就是看反了问法，把"找错的"做成了"找对的"。

# 第三块 🔬 习题英文原句精读（拿真题的英文逐句拆）

> 格式：**📖英文原句**（习题原文）→ **🇨🇳中文** → **🔍拆解关键词 + 逻辑**。看完你再看到这句就秒懂。

## 3-A　Practice_examples（老师发的 7 题，最像真考）

### P1
**📖** *"You're using a 2Q buffer replacement policy with a 3-frame buffer pool. The next page reference is 6. What are the queues after this access?"*
**🇨🇳** 你用 2Q 缓冲替换策略，3 帧缓冲池。下一个被引用的页是 6。这次访问后两个队列变成什么样？
**🔍** `buffer replacement policy`=缓冲替换策略；`3-frame`=能装 3 页；`page reference`=页引用(访问一个页)。**逻辑**：页 6 是新页→进 FIFO；池满→2Q 先驱逐 FIFO 里的页 5。

### P2
**📖** *"Based on the insights presented in the 'What Goes Around…' paper, which statement is not correct? … The column-family (wide-column) model is a columnar data model tailored for OLAP."*
**🇨🇳** 根据"What Goes Around"论文，哪个说法**不对**？……column-family（宽列）模型是为 OLAP 定制的列式数据模型。
**🔍** `insights`=观点/洞见；`tailored for`=为…量身定制。**逻辑**：这句是**错的**——论文说 column-family **不是**列式模型，是文档模型的简化版。看到 `column-family … columnar … OLAP` 摆一起 = 陷阱。

### P3
**📖** *"Why might one prefer using map over unordered_map in a database index? … To support efficient range queries."*
**🇨🇳** 为什么数据库索引里可能更偏好 `map` 而非 `unordered_map`？……为了支持高效的范围查询。
**🔍** `prefer X over Y`=偏好X而非Y；`range queries`=范围查询(如薪资 5000–10000)。**逻辑**：map 有序(红黑树)→擅长范围查询。这是对的选项。

### P4
**📖** *"…comparing Lakehouse against a classic database like PostgreSQL, which statement is NOT correct? … Because table formats bring ACID to object storage, lakehouses can outperform PostgreSQL on low-latency transactions."*
**🇨🇳** 比较 Lakehouse 和经典数据库(如 PostgreSQL)，哪个**不对**？……因为表格式给对象存储带来 ACID，lakehouse 能在低延迟事务上超过 PostgreSQL。
**🔍** `outperform`=胜过；`low-latency transactions`=低延迟事务(=OLTP)。**逻辑**：**错**！lakehouse 面向 OLAP、对象存储延迟高，**不擅长**低延迟事务。

### P5
**📖** *"Bank transfer crashes after debit but before credit. Which ACID properties ensure no money is lost?"*
**🇨🇳** 银行转账在**扣款后、入账前**崩溃。哪些 ACID 性质保证不丢钱？
**🔍** `debit`=扣款(从A减)；`credit`=入账(给B加)；`crashes`=崩溃。**逻辑**：原子性(回滚半截扣款)+持久性(日志活下来供恢复)=**Atomicity & Durability**。

### P6 / P7（重复）
**📖** *"Which statement about ordering, indexing, and access path independence is incorrect according to Codd's paper? … The presence or absence of an index should not affect query results, but an application may still reference a specific index name for performance tuning."*
**🇨🇳** 据 Codd，关于排序/索引/访问路径独立性，哪个**不正确**？……索引有无不应影响查询结果，但应用**仍可引用特定索引名**做性能调优。
**🔍** `presence or absence`=有或没有；`reference a specific index name`=引用某个具体索引名；`performance tuning`=性能调优。**逻辑**：**错**！应用引用索引名正是 Codd 要消灭的**索引依赖**。

## 3-B　Excerise_sheet_01_example（5 题示例）

### E1
**📖** *"What does the atomicity property guarantee in this transaction? … Both updates must succeed together, or neither should affect the database."*
**🇨🇳** 这个事务里原子性保证什么？……两次更新要么一起成功，要么都不影响数据库。
**🔍** `guarantee`=保证；`succeed together`=一起成功；`neither`=两者都不。**逻辑**：这就是原子性=全有或全无。

### E2
**📖** *"Determine the number of CPU cores required to serve the workload with each design."*
**🇨🇳** 算出每种设计服务该负载所需的 CPU 核数。
**🔍** `Determine`=求出；`workload`=工作负载；`cores required`=所需核数。**逻辑**：核数 = 总CPU时间需求/1秒；无槽要平均扫一半元组。

### E3
**📖** *"Which of the following statements is correct? … With Design 2, all student enrollments can be stored."*
**🇨🇳** 下面哪个**正确**？……用设计2，所有选课记录都能存下。
**🔍** `enrollments`=选课记录；`can be stored`=能存下。**逻辑**：复合主键 (StudentID,CourseID) 才能存多对多。

### E4
**📖** *"If bulkLoad(10) is called, how many pages are freed during exception unwinding?"*
**🇨🇳** 调用 bulkLoad(10)，异常栈展开期间释放了几个页？
**🔍** `exception unwinding`=异常栈展开(抛异常时逐层销毁局部对象)；`freed`=被释放。**逻辑**：i==5 抛异常前已 push 5 个 unique_ptr→栈展开全释放=5。

### E5
**📖** *"Holding only the frame's latch (with pin count = 0) is sufficient to prevent eviction while you use raw pointers into the frame's data."*
**🇨🇳** 只持有帧的闩锁(pin 计数=0)就足以在你用裸指针访问帧数据时防止驱逐。
**🔍** `Holding … latch`=持有闩锁；`sufficient to prevent eviction`=足以防驱逐；`raw pointers`=裸指针。**逻辑**：**错**！latch 防并发改、**pin** 才防驱逐；pin=0 的帧随时被驱逐。

## 3-C　Excerise_sheet_01（35 题）英文难句速读

> 每题给最关键的英文句 + 中文 + 秒懂点。（完整中文解析见 `11_例题完整解析`；这里专练"读英文"。）

| # | 英文关键句（节选） | 中文 + 秒懂点 |
|:--:|:---|:---|
| 1 | *"explicitly attempts an extra `getline` … immediately returning false if it succeeds"* | 故意多读一次，成功就返回 false = **严格校验列数**(`enforce the schema`=强制 schema) |
| 2 | *"Passing/moving a unique_ptr into a write function serializes the pointed data"* | 把 unique_ptr 传进 write 就序列化所指数据 = **错**(传指针≠序列化) |
| 3 | *"writes the tuple-count metadata after all tuple bytes"* | 元组数量元数据写在所有元组**之后** → 读者得 seek 到末尾，复杂化 |
| 4 | *"Deep copy minimizes memory usage by sharing common buffers"* | 深拷贝靠**共享缓冲**省内存 = **错**(共享是浅拷贝) |
| 5 | *"sequential prefetching becomes less critical because random page fetches are already fast"* | SSD 上顺序预取没那么关键(随机已快)——这句**对**；错的是"缓冲池大小不重要" |
| 6 | *"stack unwinding destroys buf … no manual delete[] is needed"* | 栈展开自动销毁、**无需手动 delete** = 对；错的是"必须 catch 里 delete" |
| 7 | *"raw pointers are neither stored nor meaningful"* | 裸指针**既不存也无意义** = 内存vs磁盘的正确描述 |
| 8 | *"Encapsulation should be avoided for performance"* | 为性能**避免封装** = **错**(封装是好事) |
| 9 | *"They are primarily long scan-heavy transactions"* | (OLTP)主要是**长扫描事务** = **错**(那是 OLAP) |
| 10 | *"Add a composite index on Users(Location, Username)"* | 加**复合索引** = 正确优化(过滤列在前、分组列在后) |
| 11 | *"tuples can grow in place without relocation"* | 元组能**原地增长无需重定位** = **错**(槽页不保证) |
| 12 | *"preventing update anomalies"* | 防**更新异常** = 范式化的好处 |
| 13 | *"a portable and safe mechanism for converting any pointer type"* | reinterpret_cast 是**可移植安全**的 = **错**(危险) |
| 14 | *"Either both updates take effect or neither does"* | 两更新**要么都生效要么都不** = 原子性 |
| 15 | *"at runtime the choice cannot change without relinking"* | 运行时不重链接就不能换 = **错**(多态运行时可换) |

# 第四块 📝 英文阅读速成技巧

1. **先读题干最后那个词**：是 `NOT correct` / `incorrect`（找假的）还是 `correct` / `best`（找真的）？圈出来。
2. **认副词陷阱**：`always, never, only, must, immediately, significantly, sufficient` —— 这些"绝对/夸大"词常出现在**错误**选项里。
3. **认"概念调包"**：句子把两个概念对调（deep copy 说成 sharing、column-family 说成 columnar、σ 说成 SELECT columns）——一眼识破。
4. **论文题先回忆论点**：看到 `Based on the … paper`，先想这篇论文的核心结论，再去选项里找"与结论矛盾"的那句。
5. **代码题先看在改什么状态**：`pin count`、`exclusive flag`、`use counter`、`dirty` —— 锁定它在动哪个变量。
6. **数字题圈单位**：`ms / µs / ns`、`$/Mops`、`KiB / KB` —— 换算别错。

> 🎯 **一句话**：考试的英文 = 固定的"问法外壳" + 我们这份术语表里的名词 + 论文/机制的逻辑。**外壳练到秒懂、名词中英都认得、逻辑想清楚**，英文题就和中文题一样快。
