# Part A · Module 1 — 关系模型与关系代数（Relational Model）

### A1 [M1]
**EN:** Which statement about the relational model (Codd) is **NOT** correct?
A) A relation is a set of tuples; the order of tuples is immaterial.
B) All tuples in a relation are distinct.
C) Duplicate rows are allowed because a relation is a multiset.
D) Each attribute draws values from a domain, normally atomic.
**CN:** 关于关系模型，哪个**不对**？A) 关系是元组集合，元组顺序无所谓　B) 关系中所有元组互不相同　C) 允许重复行，因为关系是多重集　D) 每个属性取值于一个域，通常是原子的
> **✅ C** — 关系是**集合**，行**不重复**；C 说"允许重复/多重集"错。A/B/D 都是 Codd 关系性质。

### A2 [M1]
**EN:** In relational algebra, which mapping to SQL is **incorrect**?
A) σ (selection) ↔ WHERE　B) Π (projection) ↔ SELECT columns　C) σ ↔ SELECT columns　D) ⋈ (join) ↔ JOIN ... ON
**CN:** 关系代数到 SQL 的对应，哪个**错**？A) σ↔WHERE　B) Π↔SELECT 列　C) σ↔SELECT 列　D) ⋈↔JOIN...ON
> **✅ C** — σ（选择）对应 **WHERE**（筛行）；SELECT 列对应**投影 Π**。经典调包陷阱。

### A3 [M1]
**EN:** A many-to-many `Enrollments(StudentID, CourseID)` table. Which primary-key design lets **all** enrollments be stored?
A) PK = StudentID only　B) PK = CourseID only　C) PK = (StudentID, CourseID)　D) No primary key
**CN:** 多对多 Enrollments 表，哪种主键能存下**所有**选课？A) 单列 StudentID　B) 单列 CourseID　C) 复合 (StudentID,CourseID)　D) 无主键
> **✅ C** — 复合主键唯一标识一条"学生-课"；单列做主键会限制每学生/每课只一行。

### A4 [M1]
**EN:** Which is **NOT** a limitation of a flat-file database that the relational model addresses?
A) Data redundancy and update anomalies　B) Slow sequential-scan lookups　C) Declarative SQL queries without writing code　D) Uncoordinated concurrent updates overwriting each other
**CN:** 哪个**不是** flat-file 的局限（关系模型来解决的）？A) 冗余与更新异常　B) 顺序扫描查找慢　C) 无需写代码的声明式 SQL 查询　D) 无协调的并发更新互相覆盖
> **✅ C** — 声明式 SQL 是关系模型的**优点**，不是 flat-file 的问题。

### A5 [M1]
**EN:** A query filters by `Location` then groups by `Username`. Given indexes on Users(UserID) and Users(Location), which physical change most likely helps?
A) Replace join with subquery　B) Drop the Location index　C) Add a composite index Users(Location, Username)　D) Change Posts index to (PostID)
**CN:** 查询先按 Location 过滤再按 Username 分组。哪个物理改动最可能提速？A) 用子查询替 join　B) 删 Location 索引　C) 加复合索引 Users(Location,Username)　D) Posts 索引改成 (PostID)
> **✅ C** — 复合索引 (Location,Username) 同时服务过滤列在前、分组列在后。

### A6 [M1·Ch2]
**EN:** Which about keys is **NOT** correct?
A) A superkey uniquely identifies a tuple but may have redundant attributes.
B) A candidate key is a minimal superkey.
C) A foreign key in R must equal the primary key of R itself.
D) A primary key is one chosen candidate key.
**CN:** 关于键，哪个**不对**？A) 超键能唯一标识元组但可能有冗余属性　B) 候选键是最小超键　C) R 的外键必须等于 R 自己的主键　D) 主键是被选中的某个候选键
> **✅ C** — 外键引用**另一张表**的主键（也可同表但指主键，不是"R 自己的主键=外键"这种说法）。

# Part B · Module 2 — BuzzDB / C++ / 事务与 ACID

### B7 [M2]
